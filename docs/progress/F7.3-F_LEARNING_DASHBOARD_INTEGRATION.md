## 1. Summary (Tóm tắt tổng quan)

Giai đoạn **F7.3-F** đã hoàn thành việc tích hợp toàn diện các chức năng học tập từ F7.3-A đến F7.3-E vào **Student Learning Dashboard** (`/my-courses` và `/`).

Học viên giờ đây có một trung tâm học tập hoàn chỉnh, minh bạch với dữ liệu thực tế từ backend:
- Theo dõi toàn bộ khóa học đã đăng ký kèm tiến độ học tập thực tế.
- Phân loại rõ ràng trạng thái: **Chưa bắt đầu** (0%), **Đang học** (1–99%), **Đã hoàn thành** (100% hoặc `COMPLETED`).
- Tính toán chính xác tỷ lệ hoàn thành trung bình (`Overall Learning Progress`) qua toàn bộ các khóa học.
- Khối **Tiếp tục học gần đây (Continue Learning Hero)** thông minh: tự động phân tích bài học chưa hoàn thành gần nhất từ `Progress API` và cung cấp nút *"Tiếp tục học ngay"* điều hướng trực tiếp vào bài học đó trong Classroom (`/learn/[slug]?lesson=[nextLessonId]`).
- Tách biệt rõ ràng danh sách khóa học đã hoàn thành (`Filter: Đã hoàn thành`) và liên kết ôn tập bài giảng / chứng chỉ.

Tất cả tính năng được xây dựng trên **100% dữ liệu thực tế từ Backend REST API**, không sửa đổi backend, không can thiệp database, không tạo endpoint mới, và không sử dụng dữ liệu giả (fake mock).

## 5. Learning Dashboard Features (Các chức năng Dashboard)

### A. Learning Overview
- **Khóa học tham gia**: Đếm tổng bản ghi enrollment hợp lệ (`status !== 'CANCELED'`).
- **Đang trong tiến trình**: Đếm các khóa có `0 < progress < 100` và `status !== 'COMPLETED'`.
- **Khóa học hoàn thành**: Đếm các khóa có `progress === 100` hoặc `status === 'COMPLETED'`.
- **Tiến độ học trung bình**:
  $$\text{overallProgress} = \text{round}\left(\frac{\sum \text{progress}}{\text{totalCourses}}\right)$$

### B. Continue Learning
- Tự động phát hiện khóa học đang học có tương tác gần nhất.
- Truy vấn danh sách bài học từ `Progress API`.
- Xác định bài học tiếp theo chưa hoàn thành (`completed === false`).
- Nút CTA điều hướng có query parameter: `/learn/[slug]?lesson=[nextLessonId]`.

### C. My Courses (Lưới & Danh sách)
- Hỗ trợ chuyển đổi giao diện Lưới (Grid) và Danh sách (List).
- Thanh tìm kiếm theo tên khóa học tức thời.
- Sắp xếp theo: Học gần đây nhất, Tiến độ cao nhất, Tiến độ thấp nhất, Tên A-Z.

### D. Completed Courses
- Hiển thị rõ ràng các khóa học hoàn thành kèm ngày hoàn thành (`completedAt`).
- Cung cấp hành động *"Ôn tập"* và liên kết tới trang Chứng chỉ.

### E. Filters
- Tích hợp 4 tab lọc: Tất cả, Đang học, Đã hoàn thành, Chưa bắt đầu.
- Tự động lọc danh sách và hiển thị Empty State tương ứng nếu không có khóa học nào thuộc phân loại.

## 6. Progress Calculation Logic (Logic tính toán tiến độ)

```typescript
// Ưu tiên dữ liệu chi tiết từ Progress API, sau đó fallback sang Enrollment progress
const progressDetail = progressMap[courseId];
const progressVal = progressDetail?.percent !== undefined
  ? Math.min(100, Math.max(0, progressDetail.percent))
  : Math.min(100, Math.max(0, enrollment.progress ?? 0));

const isDone = progressVal >= 100 || enrollment.status === 'COMPLETED';
const isNotStarted = progressVal === 0 && !isDone;
const isInProgress = progressVal > 0 && !isDone;
```

## 7. Continue Learning Navigation Logic (Logic điều hướng bài học tiếp theo)

```typescript
const getNextLesson = (courseId: string) => {
  const detailed = progressMap[courseId];
  if (!detailed || !detailed.lessons || detailed.lessons.length === 0) return null;

  // Sắp xếp bài học theo thứ tự tăng dần
  const sorted = [...detailed.lessons].sort((a, b) => (a.order ?? 0) - (b.order ?? 0));

  // Tìm bài học đầu tiên chưa hoàn thành
  const nextUncompleted = sorted.find((l) => !l.completed);
  if (nextUncompleted) {
    return {
      id: nextUncompleted.id || nextUncompleted._id || '',
      title: nextUncompleted.title || '',
      order: nextUncompleted.order ?? 1,
    };
  }

  // Nếu tất cả đã hoàn thành, trả về bài học đầu tiên để ôn tập
  const first = sorted[0];
  return {
    id: first.id || first._id || '',
    title: first.title || '',
    order: first.order ?? 1,
  };
};

// URL đích khi nhấn "Tiếp tục học ngay"
const learnUrl = nextLesson
  ? `/learn/${encodeURIComponent(courseSlug)}?lesson=${encodeURIComponent(nextLesson.id)}`
  : `/learn/${encodeURIComponent(courseSlug)}`;
```

## 8. Loading / Error / Empty States (Xử lý các trạng thái UX)

1. **Loading State**: Hiển thị Skeleton Loader hiệu ứng pulse cho toàn bộ card khi đang fetch dữ liệu từ API.
2. **Error State**: Khối cảnh báo màu hồng-đỏ kèm nút *"Thử lại ngay"* gọi lại `loadEnrollments()`. Lỗi fetch chi tiết một khóa học không làm sập toàn bộ dashboard (sử dụng `Promise.allSettled`).
3. **Empty State**:
   - Khi chưa ghi danh khóa học nào: Hiển thị icon sách, thông điệp hướng dẫn và nút *"Khám phá khóa học"*.
   - Khi tìm kiếm hoặc lọc không có kết quả: Hiển thị nút *"Xóa bộ lọc"*.
4. **Unauthenticated State**: Yêu cầu đăng nhập kèm nút dẫn tới trang Login với redirect URL.
5. **Stale Data Revalidation**: Tự động revalidate khi người dùng quay lại tab trình duyệt (`visibilitychange`, `focus`).

## 10. Backend Gaps (Khoảng trống Backend được ghi nhận)

1. **Không có API danh sách chứng chỉ học viên (`GET /api/certificates/my`)**:
   - Backend hiện chỉ cung cấp `POST /api/certificates/` để yêu cầu tạo chứng chỉ cho một khóa học cụ thể. Không có endpoint để lấy danh sách các chứng chỉ đã được cấp của học viên.
   - *Cách xử lý phía Frontend*: Trang `/my-courses` hiển thị số chứng chỉ đủ điều kiện dựa trên các khóa học đã hoàn thành (`status === 'COMPLETED'` hoặc `progress === 100`) và chuyển hướng tới `/certificates`.
2. **`GET /api/enrollments/my` không bao gồm danh sách bài học chi tiết**:
   - API enrollment chỉ trả về % tiến độ tổng quát, không chứa thông tin các bài học con.
   - *Cách xử lý phía Frontend*: Frontend thực hiện fetch song song bất đồng bộ `progressService.getCourseProgress` bằng `Promise.allSettled` để lấy danh sách bài học mà không làm chậm trải nghiệm người dùng.
