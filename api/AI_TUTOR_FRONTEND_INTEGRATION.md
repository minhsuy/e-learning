## 1. Overview & Architecture

The TMdemy AI Tutor enables learners to receive grounded, conversational assistance while studying course lessons.
All answers generated by the AI Tutor are strictly anchored to the specific lesson's video transcript using pgvector embeddings and Google Gemini RAG.

### Architectural Invariants:
1. **Frontend-Only Scope:** The frontend communicates with the backend exclusively via REST API (`/api/v1/ai-tutor`) using `src/lib/api/client.ts`. It never calls Gemini or Python microservices directly.
2. **Citation Invariant:** Every citation timestamp (`startTime`, `endTime`) is in **seconds** (float), never milliseconds.
3. **Session Scope:** Sessions are strictly scoped to the `(student, lesson)` pair.
4. **Messenger-Style Floating Bubble UI:** AI Tutor is presented as a floating circular launcher (`AiTutorFloatingChat`) anchored in the bottom-right corner of the classroom (`/learn/[slug]`). Clicking the bubble expands a non-modal floating chat window (`w-[410px]`, `h-[580px]` on desktop, responsive bottom-sheet on mobile) that allows students to chat and study concurrently without interrupting video playback.
5. **Presentation Sanitization:** Raw RAG tags (e.g. `[CHUNK:uuid]`) in assistant messages are sanitized at the presentation layer via `sanitizeAiTutorAnswer` before Markdown rendering and clipboard copying, while structured `CitationDto` objects remain 100% intact as clickable badges.
6. **Canonical Avatar Asset:** Uses `/icon.png` (`public/icon.png`) for all AI Tutor visual entry points.
7. **Chat Persistence & State Restoration:** On lesson mount and page refresh, the frontend automatically queries `GET /api/v1/ai-tutor/lessons/:lessonId/sessions` to identify the most recent active session, and immediately issues `GET /api/v1/ai-tutor/sessions/:sessionId` to populate conversation history. Both backend payload conventions (`messages` at top level or nested in `data.messages`) are seamlessly supported and ordered chronologically by `createdAt asc`.
8. **Video Seeking Priority & Player.js Protocol:** Seeking strictly follows the active video player priority:
   - Priority 1: Bunny Stream CDN iframe (via Player.js postMessage `method: 'setCurrentTime'` and `method: 'play'`).
   - Priority 2: YouTube Embed iframe (via `seekTo` postMessage).
   - Priority 3: Direct HTML5 Video (`video.currentTime = seconds`).
   - If user clicks a timestamp citation before Bunny Stream finishes initializing, the seek is queued in `pendingSeekSecondsRef` and automatically dispatched upon receiving the Player.js `ready` event or iframe `onLoad`.

## 2. API Endpoints Contract

### 2.1 Create Conversation Session
- **Route:** `POST /api/v1/ai-tutor/lessons/:lessonId/sessions`
- **Auth:** Required (Student enrolled or free preview access)
- **Request Body:**
  ```json
  {
    "title": "Tìm hiểu kiến thức bài học" // Optional, max 120 chars
  }
  ```
- **Response `201 Created`:**
  ```json

    "statusCode": 201,
    "message": "Phiên trò chuyện đã được tạo",
  ```

### 2.5 Update Session (Rename / Archive)
- **Route:** `PATCH /api/v1/ai-tutor/sessions/:sessionId`
- **Request Body:**
  ```json
  {
    "title": "Tên phiên hội thoại mới",
    "isActive": false // Set to false to archive
  }
  ```
- **Response `200 OK`:** Updated `AiTutorSession` DTO.

### 2.6 Delete Session
- **Route:** `DELETE /api/v1/ai-tutor/sessions/:sessionId`
- **Contract Behavior:**
  - If session has messages: Soft-archives session (`isActive = false`), action: `"ARCHIVED"`.
  - If session has 0 messages: Hard-deletes session, action: `"DELETED"`.

## 3. Video Player Seeking Protocol

Clicking a citation badge triggers `handleSeekVideo(seconds: number)` in `src/app/learn/[slug]/page.tsx`:

```typescript
// 1. Direct HTML5 Video
if (directVideoRef.current) {
  directVideoRef.current.currentTime = seconds;
  directVideoRef.current.play();
}

// 2. Bunny Stream Player (Player.js standard & Direct postMessage)
if (bunnyIframeRef.current?.contentWindow) {
  bunnyIframeRef.current.contentWindow.postMessage(
    JSON.stringify({
      context: 'player.js',
      version: '0.0.11',
      event: 'command',
      command: 'setCurrentTime',
      value: seconds,
    }),
    '*'
  );
  bunnyIframeRef.current.contentWindow.postMessage(
    JSON.stringify({ context: 'player.js', version: '0.0.11', event: 'command', command: 'play' }),
    '*'
  );
  bunnyIframeRef.current.contentWindow.postMessage({ method: 'setCurrentTime', value: seconds }, '*');
  bunnyIframeRef.current.contentWindow.postMessage({ method: 'play' }, '*');
}

// 3. YouTube Embed Player
if (youtubeIframeRef.current?.contentWindow) {
  youtubeIframeRef.current.contentWindow.postMessage(
    JSON.stringify({ event: 'command', func: 'seekTo', args: [seconds, true] }),
    '*'
  );
}
```

## 4. Citation Marker Sanitization (`sanitizeAiTutorAnswer`)

Raw Gemini responses contain internal tracking markers such as `[CHUNK:uuid]` or `[CHUNK:uuid1, CHUNK:uuid2]`.
These are purified before rendering via `src/lib/sanitize-ai-tutor.ts`:

- Strips `[CHUNK:...]` patterns cleanly.
- Fixes punctuation spacing (e.g., `constructor [CHUNK:...].` -> `constructor.`).
- Preserves code blocks (```` ```...``` ````) and inline code (`` `...` ``).
- Preserves legitimate markdown links `[Title](url)` and syntax `arr[0]`.
- Applied both to UI presentation (`ReactMarkdown`) and clipboard copying (`handleCopy`).

## 5. RAG Diagnostics & Status Codes

| RAG Status | Description | UI Action |
|---|---|---|
| `ANSWERED` | Direct transcript context found, answer generated with citations | Green citation badges rendered, clickable for seek |
| `INSUFFICIENT_CONTEXT` | Question out-of-scope of video transcript | Alert info banner displayed: question exceeded lesson scope |
| `INDEX_NOT_READY` | Video transcript embedding in progress | Warning banner displayed: background indexing active |
| `INDEX_STALE` | Lesson updated recently, index synchronizing | Info banner displayed: re-indexing new lesson version |
